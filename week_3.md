## 1. Теоретический блок (25 минут)
## Что такое State и чем он отличается от Props

* Props — это входные данные, которые передаются компоненту снаружи от родителя. Они неизменяемы (Read-Only). Это аналог ```input()``` или ```@Input()``` в Angular.
* State (Состояние) — это внутреннее хранилище данных компонента. Компонент сам управляет своим состоянием. Когда состояние изменяется, React автоматически перерисовывает (делает ререндер) этот компонент и его детей.

## Знакомство с хуками и ```useState```
Хуки — это специальные функции, которые позволяют «подключиться» к возможностям React (состоянию, жизненному циклу) внутри функциональных компонентов. Их имена всегда начинаются с ```use```.
Хук ```useState``` принимает начальное значение и возвращает массив из двух элементов:

   1. Текущее значение состояния.
   2. Функция для обновления этого состояния.

```jsx
const [count, setCount] = useState(0);
```

## Правила использования хуков (Rules of Hooks)

   1. Только на верхнем уровне: Нельзя вызывать хуки внутри циклов, условий или вложенных функций. React полагается на порядок вызова хуков при каждом рендере.
   2. Только в компонентах или кастомных хуках: Их нельзя вызывать в обычных JavaScript-функциях.

## Асинхронность и батчинг (Batching)
Функция обновления состояния (например, ```setCount```) работает асинхронно. Если вы вызовете ```setCount(count + 1)``` и сразу на следующей строчке попытаетесь вывести ```console.log(count)```, вы увидите старое значение.
React также использует батчинг — он объединяет несколько обновлений состояния в одно, чтобы избежать лишних ререндеров и не тормозить интерфейс.

## Иммутабельность (Неизменяемость)
Если состояние — это объект или массив, его нельзя мутировать напрямую.

* Неправильно: ```user.name = 'Иван'; setUser(user)```; — React не заметит изменений, так как ссылка на объект осталась прежней, и ререндер не произойдет.
* Правильно: Создать копию объекта/массива через spread-оператор (```...```), изменить нужное свойство и передать новую ссылку: ```setUser({ ...user, name: 'Иван' });```.

## 2. Практический блок (15 минут)
## Шаг 1. Создаем интерактивный счетчик
Создадим файл ```src/components/Counter.jsx```, который демонстрирует базовую работу с состоянием и правильное обновление на основе предыдущего значения:
```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  const handleIncrement = () => {
    // Если новое состояние зависит от предыдущего, 
    // передаем функцию-колбэк во избежание багов асинхронности
    setCount(prevCount => prevCount + 1);
  };

  const handleDecrement = () => {
    setCount(prevCount => prevCount - 1);
  };

  return (
    <div style={{ border: '1px solid #aaa', padding: '16px', borderRadius: '8px', margin: '10px 0' }}>
      <h3>Счетчик кликов</h3>
      <p>Текущее значение: <strong>{count}</strong></p>
      <button onClick={handleDecrement}>Уменьшить</button>
      <button onClick={handleIncrement} style={{ marginLeft: '8px' }}>Увеличить</button>
    </div>
  );
}

export default Counter;
```
## Шаг 2. Работа со сложным состоянием (Массив объектов)
Создадим форму добавления задач ```src/components/TodoList.jsx```. Здесь мы покажем, как правильно добавлять элементы в массив, сохраняя иммутабельность:
```jsx
import { useState } from 'react';

function TodoList() {
  const [todos, setTodos] = useState([
    { id: 1, text: 'Изучить основы React' },
    { id: 2, text: 'Разобраться с useState' }
  ]);
  
  // Дополнительное состояние для хранения текста из инпута
  const [inputValue, setInputValue] = useState('');

  const addTodo = () => {
    if (inputValue.trim() === '') return;

    const newTodo = {
      id: Date.now(), // Генерируем простой ID
      text: inputValue
    };

    // Обновляем массив: создаем новый массив, разворачивая старый 
    // и добавляя в конец новый элемент
    setTodos([...todos, newTodo]);
    setInputValue(''); // Очищаем инпут
  };

  return (
    <div style={{ marginTop: '20px' }}>
      <h3>Мой список задач</h3>
      
      <input 
        type="text" 
        value={inputValue} 
        onChange={(e) => setInputValue(e.target.value)} 
        placeholder="Новая задача..."
      />
      <button onClick={addTodo} style={{ marginLeft: '8px' }}>Добавить</button>

      <ul>
        {todos.map(todo => (
          <li key={todo.id}>{todo.text}</li>
        ))}
      </ul>
    </div>
  );
}

export default TodoList;
```
