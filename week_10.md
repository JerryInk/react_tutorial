## Лекция 10: Продвинутые паттерны и экосистема

* Длительность: 45 минут
* Сложность: Продвинутая
* Цель: Изучить механизмы работы с порталами, предохранителями ошибок и ленивой загрузкой, а также получить общую карту современной экосистемы React.

------------------------------
## 1. Теоретический блок (25 минут)
На этой лекции мы разберем инструменты, которые выводят архитектуру приложения на уровень production-готовности.
## Порталы (React Portals)
Обычно дочерний компонент рендерится строго внутри своего родительского DOM-узла. Но для модальных окон, тултипов или выпадающих меню это проблема: если у родителя стоит ```overflow: hidden``` или специфический ```z-index```, модалка визуально «обрежется».

* Решение: ```createPortal``` позволяет отрендерить JSX-элемент в любом другом месте DOM-дерева (например, прямо в ```<body>```), сохраняя при этом его логическое положение в React-дереве (события и контекст продолжают работать как обычно).

## Предохранители ошибок (Error Boundaries)
Если в Angular падение одного компонента локализуется, то в React необработанная ошибка JS внутри метода рендера полностью ломает и гасит все приложение (белый экран).

* Решение: Error Boundary — это специальный компонент, который ловит ошибки в своих детях и вместо упавшего UI выводит запасной интерфейс (```fallback```).
* Нюанс: На сегодняшний день предохранители ошибок можно написать только как классовые компоненты (через методы ```getDerivedStateFromError``` и ```componentDidCatch```). В функциональных компонентах их заменяют готовыми библиотеками (например, ```react-error-boundary```).

## Разделение кода (Code Splitting) и Suspense
По умолчанию Vite собирает весь ваш код в один большой файл ```bundle.js```. Если проект огромный, пользователь будет долго ждать загрузки первой страницы.

* Решение: ```React.lazy``` позволяет импортировать компоненты динамически, только когда они нужны.
* Пока тяжелый компонент скачивается по сети, компонент ```<Suspense>``` показывает заглушку (лоадер). Это аналог ленивой загрузки модулей (Lazy Loading) из Angular.

## 2. Практический блок (15 минут)
## Шаг 1. Создаем Модальное окно через Портал
Создайте файл ```src/components/Modal.jsx```. Мы отрендерим его в отдельный тег вне корня React:
```jsx
import ReactDOM from 'react-dom';

function Modal({ isOpen, onClose, children }) {
  if (!isOpen) return null;

  // Рендерим разметку напрямую в document.body, минуя родительский div
  return ReactDOM.createPortal(
    <div style={{
      position: 'fixed', top: 0, left: 0, right: 0, bottom: 0,
      backgroundColor: 'rgba(0,0,0,0.5)', display: 'flex', 
      justifyContent: 'center', alignItems: 'center', zIndex: 1000
    }}>
      <div style={{ background: '#fff', padding: '20px', borderRadius: '8px', minWidth: '300px' }}>
        {children}
        <hr />
        <button onClick={onClose}>Закрыть</button>
      </div>
    </div>,
    document.body // Целевой DOM-узел вне <div id="root">
  );
}

export default Modal;
```
## Шаг 2. Ленивая загрузка компонента через ```React.lazy```
Создадим «тяжелый» компонент, который мы хотим загружать отложено — ```src/components/HeavyDashboard.jsx```:
```jsx
function HeavyDashboard() {
  return (
    <div style={{ padding: '15px', backgroundColor: '#e2e8f0', marginTop: '15px' }}>
      <h3>Панель аналитики (Загружена лениво!)</h3>
      <p>Здесь могли быть тяжелые графики и таблицы.</p>
    </div>
  );
}
export default HeavyDashboard;
```
## Шаг 3. Собираем продвинутые паттерны в ```App.jsx```
Используем ```React.lazy``` для импорта панели аналитики и подключим портальную модалку:
```jsx
import { useState, lazy, Suspense } from 'react';
import Modal from './components/Modal';

// Ленивый импорт компонента
const HeavyDashboard = lazy(() => import('./components/HeavyDashboard'));

function App() {
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [showDashboard, setShowDashboard] = useState(false);

  return (
    <div style={{ maxWidth: '500px', margin: '40px auto', fontFamily: 'sans-serif' }}>
      <h1>Продвинутые паттерны React</h1>

      {/* 1. Работа с Порталом */}
      <button onClick={() => setIsModalOpen(true)}>Открыть модалку (Portal)</button>
      <Modal isOpen={isModalOpen} onClose={() => setIsModalOpen(false)}>
        <h2>Привет из Портала!</h2>
        <p>Я нахожусь в самом низу тега body, но управляюсь из App.</p>
      </Modal>

      <hr style={{ margin: '20px 0' }} />

      {/* 2. Работа с Code Splitting и Suspense */}
      <button onClick={() => setShowDashboard(true)}>Загрузить аналитику (Lazy)</button>
      
      {showDashboard && (
        <Suspense fallback={<p>Секунду, скачиваю компонент по сети...</p>}>
          <HeavyDashboard />
        </Suspense>
      )}
    </div>
  );
}

export default App;
```

## 3. Чек-лист для самопроверки (3 минуты)

* Понимаете, почему при использовании ```createPortal``` разметка улетает в конец ```body```, но клики внутри неё всё равно всплывают до компонента ```App```.
* Знаете, почему нельзя написать предохранитель ошибок (Error Boundary) как чистый функциональный компонент.
* Помните, какой компонент обязан оборачивать ```React.lazy``` для отображения индикатора загрузки.

## 4. Карта экосистемы: Что учить дальше?
   1. Роутинг: React Router (стандарт для SPA приложений).
   2. Глобальный стейт: Zustand (легковесный, современный) или Redux Toolkit (для огромных корпоративных проектов).
   3. Запросы к API: TanStack Query (React Query) — берет на себя кэширование, лоадеры и авто-обновление данных с сервера (заменяет кастомный ```useFetch```).
   4. Фреймворки: Next.js или Remix — инструменты на базе React для Server-Side Rendering (SSR), статической генерации страниц и SEO оптимизации.
