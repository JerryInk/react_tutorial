## Лекция 6: Стилизация в React

* Длительность: 45 минут
* Сложность: Начальная
* Цель: Изучить ключевые подходы к стилизации React-приложений, научиться изолировать стили с помощью CSS-модулей и динамически управлять классами.

------------------------------
## 1. Теоретический блок (25 минут)
В Angular стили изолированы «из коробки» благодаря механизму ViewEncapsulation. В React встроенной изоляции нет: если вы импортируете обычный файл ```.css```, его правила станут глобальными для всего приложения. Для решения этой проблемы экосистема использует три основных подхода.

## Подход 1: CSS-модули (CSS Modules)
Это встроенный в Vite стандарт изоляции. Вы создаете файл с расширением ```.module.css```. При сборке инструменты автоматически переименовывают классы, добавляя к ним уникальный хэш.

* Исходный класс: ```.card```
* Итоговый класс в браузере: ```._card_1abc2_5```
Благодаря этому стили разных компонентов никогда не пересекаются.

## Подход 2: Инлайн-стили (Inline Styles)
Атрибут ```style``` в React принимает не строку, а объект JavaScript, где свойства пишутся в формате camelCase (например, ```backgroundColor``` вместо ```background-color```).

* Подходит для динамических вычислений (например, положение ползунка или ширина прогресс-бара).
* Не подходит для сложных стилей (псевдоклассы ```:hover```, медиа-запросы ```@media```).

## Подход 3: Утилитарные фреймворки (Tailwind CSS)
Современный стандарт индустрии. Вместо написания CSS вы используете готовые атомарные классы прямо в JSX. Отлично сочетается с компонентным подходом React, избавляя от необходимости постоянно придумывать имена для классов.

## Динамические классы
Когда нужно включить или выключить класс по условию, писать громоздкие тернарные операторы неудобно. В React-сообществе для этого используют легковесную библиотеку clsx (или classnames).

------------------------------
## 2. Практический блок (15 минут)
## Шаг 1. Создаем CSS-модуль
Создайте файл ```src/components/Alert.module.css```. Обратите внимание на расширение:
```css
.alertBox {
  padding: 16px;
  border-radius: 6px;
  border: 1px solid #ccc;
  margin-bottom: 12px;
  transition: all 0.2s ease;
}
/* Стили для разных состояний */
.success {
  background-color: #e6fffa;
  border-color: #319795;
  color: #234e52;
}

.danger {
  background-color: #fff5f5;
  border-color: #e53e3e;
  color: #742a2a;
}
```
## Шаг 2. Применяем стили и динамические классы
Установим утилиту clsx для удобной склейки классов по условию:
```bash
npm install clsx
```
Создадим компонент уведомления ```src/components/Alert.jsx```. Импортируем стили как объект ```styles```:
```jsx
import clsx from 'clsx';
import styles from './Alert.module.css';

function Alert({ text, type }) {
  // Динамически формируем строку классов.
  // Класс styles.alertBox применится всегда.
  // Класс styles.success применится только если type === 'success'.
  const alertClassName = clsx(styles.alertBox, {
    [styles.success]: type === 'success',
    [styles.danger]: type === 'danger',
  });

  return (
    <div className={alertClassName}>
      <p style={{ margin: 0, fontWeight: 'bold' }}>{text}</p>
    </div>
  );
}

export default Alert;
```
## Шаг 3. Инлайн-стили для динамики в App.jsx
Обновим файл ```src/App.jsx```. Добавим управление уведомлениями и пример инлайн-стилей:
```jsx
import { useState } from 'react';
import Alert from './components/Alert';

function App() {
  const [fontSize, setFontSize] = useState(16);

  return (
    <div style={{ maxWidth: '400px', margin: '40px auto', fontFamily: 'sans-serif' }}>
      <h1>Стилизация в React</h1>
      
      {/* Использование CSS-модулей с динамикой */}
      <Alert text="Операция прошла успешно!" type="success" />
      <Alert text="Произошла критическая ошибка." type="danger" />

      <hr style={{ margin: '20px 0' }} />

      {/* Пример инлайн-стилей для динамически изменяемых свойств */}
      <div style={{ border: '1px solid #aaa', padding: '10px' }}>
        <p style={{ fontSize: `${fontSize}px`, margin: '0 0 10px 0' }}>
          Размер этого текста: {fontSize}px
        </p>
        <button onClick={() => setFontSize(prev => prev + 2)}>Увеличить шрифт</button>
        <button onClick={() => setFontSize(prev => prev - 2)} style={{ marginLeft: '8px' }}>Уменьшить шрифт</button>
      </div>
    </div>
  );
}

export default App;
```

## 3. Чек-лист для самопроверки (3 минуты)

* Понимаете, почему импорт ```import './style.css'``` внутри компонента может сломать стили на других страницах.
* Знаете, как Vite переименовывает классы при использовании CSS-модулей.
* Умеете записывать CSS-свойства в инлайн-стилях (например, ```text-align -> textAlign```).
* Понимаете, какую задачу решает библиотека clsx.
