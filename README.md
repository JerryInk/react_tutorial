Этот курс мы построим по принципу «от фундамента к продвинутым паттернам», чтобы структура была максимально понятной и практичной.
Ниже представлен готовый план курса из 10 лекций. Каждую из них мы можем подробно расписать с примерами кода.
------------------------------
## Курс лекций: Современный React (с нуля до уровня Middle)

## Лекция 1: Введение в React и философия библиотеки

* Что такое React: библиотека или фреймворк.
* Декларативный подход против императивного.
* Как работает Virtual DOM и почему это быстро.
* Создание проекта: Vite против Next.js (почему CRA устарел).
* Структура базового проекта и JSX: синтаксис, ограничения, компиляция.

## Лекция 2: Компоненты и основы передачи данных

* Функциональные компоненты — современный стандарт.
* Что такое Props: передача данных сверху вниз.
* Деструктуризация пропсов и значения по умолчанию.
* Рендеринг списков (метод map) и важность уникальных ключей (key).
* Условный рендеринг (тернарный оператор, логическое «И»).

## Лекция 3: Состояние компонента и хук useState

* Что такое State и чем он отличается от Props.
* Хук useState: синтаксис и правила использования.
* Асинхронность обновления состояния и батчинг (batching).
* Работа с комплексным состоянием (объекты и массивы, иммутабельность).
* Поднятие состояния (Lifting State Up) для обмена данными между соседями.

## Лекция 4: Управление побочными эффектами — Хук useEffect

* Жизненный цикл компонента в мире хуков.
* Хук useEffect: анатомия, массив зависимостей.
* Синхронизация компонента с внешними системами (API, таймеры, подписки).
* Функция очистки (Cleanup function): утечки памяти и как их избежать.
* Обработка стадий: Mount, Update, Unmount.

## Лекция 5: Работа с формами и useRef

* Управляемые компоненты (Controlled) против неуправляемых (Uncontrolled).
* Сбор данных формы через useState.
* Хук useRef: доступ к DOM-элементам напрямую.
* Хранение мутирующих значений без запуска рендеринга.
* Краткий обзор библиотек для валидации (React Hook Form).

## Лекция 6: Стилизация в React

* Архитектура стилей: плюсы и минусы разных подходов.
* Вариант 1: CSS-модули (изоляция стилей).
* Вариант 2: CSS-in-JS (Styled Components / Emotion).
* Вариант 3: Утилитарные классы (Tailwind CSS) — современный тренд.
* Динамическое управление классами (библиотека clsx или classnames).

## Лекция 7: Оптимизация производительности

* Почему происходят лишние ререндеры.
* Профилирование компонентов с помощью React DevTools.
* Мемоизация компонентов через React.memo.
* Мемоизация вычислений с помощью хука useMemo.
* Стабилизация ссылок на функции с помощью хука useCallback.

## Лекция 8: Глобальное состояние без сторонних библиотек

* Проблема глубокого проброса пропсов (Prop Drilling).
* Контекст в React: React.createContext и хук useContext.
* Создание кастомного провайдера (Provider Pattern).
* Хук useReducer: управление сложной логикой состояния через экшены.
* Когда Context API не заменяет Redux/Zustand.

## Лекция 9: Кастомные хуки и переиспользование логики

* Что такое кастомный хук и зачем он нужен.
* Извлечение бизнес-логики из UI-компонентов.
* Примеры: хук для запросов данных (useFetch), хук для работы с localStorage (useLocalStorage).
* Композиция хуков (хуки внутри хуков).

## Лекция 10: Продвинутые паттерны и экосистема

* Порталы (React.createPortal) для модальных окон и тултипов.
* Обработка ошибок в UI: Предохранители (Error Boundaries).
* Разделение кода (Code Splitting): React.lazy и Suspense.
* Краткий обзор экосистемы: стейт-менеджеры (Zustand/Redux Toolkit) и роутинг (React Router).
