## 1. Теоретический блок (25 минут)
## Функциональные компоненты
В современном React компоненты — это обычные JavaScript-функции. Они принимают объект с данными и возвращают JSX-разметку.

* В отличие от Angular, где компонент состоит из трех-четырех файлов (```.ts```, ```.html```, ```.css```), в React вся логика и разметка компонента инкапсулированы в одном файле ```.jsx```.
* Название компонента обязательно должно начинаться с заглавной буквы (например, ```ProductCard```). Так React отличает кастомные компоненты от встроенных HTML-тегов (```div```, ```h1```).

## Что такое Props (Свойства)
Props — это механизм передачи данных от родительского компонента к дочернему. Это аналог декоратора ```@Input()``` или сигнала ```input()``` в Angular.

* Передача идет строго в одном направлении: сверху вниз (однонаправленный поток данных).
* Props неизменяемы (Read-Only): Компонент не имеет права модифицировать пропсы, которые он получил. Если данные нужно изменить, это делается через состояние родителя (тема следующей лекции).

## Деструктуризация пропсов
Компонент принимает один аргумент — объект ```props```. Чтобы код был чище, используют деструктуризацию JavaScript:
```javascript
// Полная запись:
function User(props) { return <h1>{props.name}</h1>; }

// Современная запись с деструктуризацией:
function User({ name }) { return <h1>{name}</h1>; }
```
## Рендеринг списков и важность ```key```
Для вывода списков в React используется стандартный метод массива ```.map()```, который возвращает массив JSX-элементов. Это заменяет директиву ```for``` из Angular.
Каждому элементу списка обязательно нужно передать уникальный атрибут ```key``` (обычно это ```id``` из базы данных).

* Зачем нужен ```key```? Он помогает Virtual DOM идентифицировать, какие именно элементы массива изменились, были добавлены или удалены.
* Использовать индекс массива (index) в качестве ```key``` крайне не рекомендуется, если порядок элементов может меняться (сортировка, удаление, фильтрация) — это приведет к багам отображения.

## 2. Практический блок (15 минут)
## Шаг 1. Создаем дочерний компонент ```ProductCard.jsx```
Создайте файл ```src/components/ProductCard.jsx```. Этот компонент будет отвечать только за отображение одной карточки товара:
```jsx
// Пример деструктуризации и задания значения по умолчанию для discount
function ProductCard({ title, price, isAvailable, discount = 0 }) {
  return (
    <div className="product-card" style={{ border: '1px solid #ccc', padding: '16px', margin: '8px' }}>
      <h3>{title}</h3>
      <p>Цена: {price} руб.</p>
      
      {/* Условный рендеринг через логическое «И» */}
      {discount > 0 && (
        <p style={{ color: 'red' }}>Скидка: {discount}%</p>
      )}

      {/* Условный рендеринг через тернарный оператор */}
      <p style={{ color: isAvailable ? 'green' : 'gray' }}>
        {isAvailable ? 'В наличии' : 'Ожидается поставка'}
      </p>
    </div>
  );
}

export default ProductCard;
```
## Шаг 2. Выводим список компонентов в ```App.jsx```
Откроем ```src/App.jsx```, импортируем наш компонент карточки и отрендерим массив данных с помощью ```.map()```:
```jsx
import ProductCard from './components/ProductCard';

function App() {
  // Имитируем массив данных из API
  const products = [
    { id: 101, title: 'Беспроводные наушники', price: 4500, isAvailable: true, discount: 10 },
    { id: 102, title: 'Игровая мышь', price: 2300, isAvailable: false },
    { id: 103, title: 'Механическая клавиатура', price: 6800, isAvailable: true, discount: 15 }
  ];

  return (
    <div className="app-container" style={{ maxWidth: '600px', margin: '0 auto' }}>
      <h1>Каталог товаров</h1>
      
      <div className="product-list">
        {products.map((product) => (
          <ProductCard 
            key={product.id} // Передаем обязательный уникальный ключ
            title={product.title}
            price={product.price}
            isAvailable={product.isAvailable}
            discount={product.discount}
          />
        ))}
      </div>
    </div>
  );
}

export default App;
```
