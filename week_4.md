* Цель: Освоить работу с побочными эффектами, понять жизненный цикл функционального компонента и научиться правильно делать запросы к API без утечек памяти.

## 1. Теоретический блок (25 минут)
## Что такое побочные эффекты (Side Effects)
Чистая функция компонента в React должна принимать пропсы и возвращать JSX, не совершая сторонних действий. Всё, что выходит за рамки этого процесса, называется побочным эффектом:

* Запросы к серверу (API).
* Настройка таймеров (```setTimeout```, ```setInterval```).
* Прямое манипулирование сторонним DOM (например, подключение плагинов).
* Подписка на глобальные события (```window.addEventListener```).

В Angular для этого используются методы жизненного цикла (```ngOnInit```, ```ngOnDestroy```). В React за все эти стадии отвечает один универсальный хук — ```useEffect```.

## Анатомия хука ```useEffect```
Хук принимает два аргумента: функцию-эффект и необязательный массив зависимостей.
```javascript
useEffect(() => {
  // Код эффекта
}, [зависимости]);
```
Поведение хука полностью зависит от массива зависимостей:

   1. Массив отсутствует: Эффект срабатывает при каждом рендере компонента. Используется редко, так как легко может вызвать зависание приложения при неаккуратном коде.
   2. Пустой массив ```[]```: Эффект срабатывает ровно один раз при монтировании компонента (аналог ```ngOnInit``` в Angular). Отлично подходит для первичной загрузки данных.
   3. Массив со значениями ```[prop, state]```: Эффект сработает при монтировании, а затем будет перезапускаться только тогда, когда изменится хотя бы одно из указанных значений.

## Функция очистки (Cleanup function)
Если эффект создает подписку или таймер, их необходимо удалить, когда компонент исчезает с экрана (размонтируется), иначе произойдет утечка памяти (аналог ```ngOnDestroy``` в Angular).
Для этого из функции-эффекта нужно вернуть другую функцию:
```javascript
useEffect(() => {
  const handleResize = () => console.log(window.innerWidth);
  window.addEventListener('resize', handleResize);

  // Функция очистки
  return () => {
    window.removeEventListener('resize', handleResize);
  };
}, []);
```

Важно: функция очистки также запускается перед каждым повторным выполнением эффекта, если изменились зависимости, чтобы «стереть» результаты предыдущего запуска.

## 2. Практический блок (15 минут)
## Шаг 1. Загрузка данных с сервера при старте
Создадим компонент ```src/components/UsersList.jsx```, который загружает список пользователей с публичного API при монтировании:
```jsx
import { useState, useEffect } from 'react';

function UsersList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // Внутри useEffect используем асинхронную функцию
    const fetchUsers = async () => {
      try {
        const response = await fetch('https://typicode.com');
        const data = await response.json();
        setUsers(data);
      } catch (error) {
        console.error("Ошибка при загрузке:", error);
      } finally {
        setLoading(false);
      }
    };

    fetchUsers();
  }, []); // Пустой массив — запрос выполнится один раз

  if (loading) return <p>Загрузка пользователей...</p>;

  return (
    <div>
      <h3>Список пользователей</h3>
      <ul>
        {users.map(user => (
          <li key={user.id}>{user.name} ({user.email})</li>
        ))}
      </ul>
    </div>
  );
}

export default UsersList;
```
## Шаг 2. Эффект с зависимостями и очисткой
Создадим компонент таймера ```src/components/Timer.jsx```, который запускается при старте и корректно уничтожается при скрытии:
```jsx
import { useState, useEffect } from 'react';

function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    // Запускаем интервал
    const intervalId = setInterval(() => {
      setSeconds(prev => prev + 1);
    }, 1000);

    // Обязательно возвращаем функцию очистки
    return () => {
      clearInterval(intervalId);
      console.log('Таймер уничтожен, утечка памяти предотвращена!');
    };
  }, []); // Пустой массив — интервал ставится один раз

  return (
    <div style={{ background: '#f0f0f0', padding: '10px', borderRadius: '5px' }}>
      <p>Время нахождения на странице: <strong>{seconds} сек.</strong></p>
    </div>
  );
}

export default Timer;
```
## Шаг 3. Переключатель компонентов в ```App.jsx```
Убедимся, что очистка работает. Добавим состояние для скрытия и показа таймера в ```src/App.jsx```:
```jsx
import { useState } from 'react';
import UsersList from './components/UsersList';
import Timer from './components/Timer';

function App() {
  const [showTimer, setShowTimer] = useState(true);

  return (
    <div style={{ maxWidth: '500px', margin: '40px auto', fontFamily: 'sans-serif' }}>
      <h1>Управление эффектами</h1>
      
      <button onClick={() => setShowTimer(!showTimer)}>
        {showTimer ? 'Скрыть таймер' : 'Показать таймер'}
      </button>
      
      {/* Условный рендеринг: при false компонент размонтируется */}
      {showTimer && <Timer />}
      
      <hr style={{ margin: '20px 0' }} />
      <UsersList />
    </div>
  );
}

export default App;
```
